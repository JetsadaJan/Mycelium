# Node (Graph & Neural)

In graph theory, neuroscience, and network biology, a **Node** (or **vertex**) is a fundamental intersection point where signals, nutrients, or data are received, processed, and routed outward along edges.

## Examples Across Biological & Computational Networks

1. **In a [[Mycelium Network]]**: Branching junctions and cords where multiple [[Hypha (Biology)|Hyphae]] fuse and redistribute minerals toward [[Mycorrhiza]] root tips.
2. **In a [[Biological Neural Network]]**: Individual neuron cell bodies (somata) that sum synaptic inputs before firing an action potential.
3. **In an [[Artificial Neural Network]]**: Mathematical activation units (perceptrons or attention heads) that transform input vectors into learned representations.
4. **In [[Colony (Mycelium Workspace)|Mycelium Software]]**: Each `.md` document is modeled as a [[Node (Mycelium Document)|Colony Node]] on the force-directed canvas.
